# النسخة السحابية — مزامنة فورية + نسخ احتياطي تلقائي

## خطوات التركيب على هوستنجر (مرة واحدة)

1. **أنشئ قاعدة بيانات MySQL** من hPanel:
   Databases ← MySQL Databases ← أنشئ قاعدة + مستخدم وكلمة مرور ← اربط المستخدم بالقاعدة.

2. **افتح `config.php`** وعدّل السطور الثلاثة (DB_NAME / DB_USER / DB_PASS) بالقيم من الخطوة 1.

3. **ارفع كل ملفات هذه المجلد** إلى `public_html` (استبدل الملفات القديمة).

4. **شغّل `install.php`** مرة واحدة من المتصفح: `yourdomain.com/install.php`
   عند ظهور "تم التثبيت بنجاح" ← **احذف ملف install.php فوراً**.

5. فعّل SSL (إن لم يكن مفعّلاً) — المزامنة تحتاج HTTPS في معظم المتصفحات.

## ما الذي تغيّر؟

- كل حفظ (إضافة/تعديل/حذف/رسالة) يُرفع للسيرفر خلال أقل من نصف ثانية → **نفس البيانات على كل الأجهزة فوراً**
- مع كل حفظ ناجح يُنشأ **نسخة احتياطية تلقائية فورية** على السيرفر (آخر 100 نسخة محفوظة)
- عند تعارض تعديلين من جهازين: تُعتمد النسخة الأحدث وتُعرض على الشاشة مباشرة
- بدون إنترنت: يعمل السيستم محلياً ويُرفع تلقائياً عند عودة الاتصال
- تنزيل نسخة JSON يدوية في أي وقت: `yourdomain.com/api.php?action=download`

## ملاحظات

- الاحتفاظ بآخر 100 نسخة احتياطية يمكن تغييره من `MAX_BACKUPS` في `config.php`
- جلسة الدخول (من مسجّل دخل) تبقى على كل جهاز على حدة — البيانات مشتركة، الدخول فردي
